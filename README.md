# Сервис рекомендаций вин

Веб-приложение на Streamlit для оценки качества вина на основе лабораторных анализов.

## Как запустить локально

1. Убедитесь, что у вас установлен **Python 3.10** (или выше).
2. Установите необходимые библиотеки:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```bash
   streamlit run app.py
   ```

## Файлы в проекте
- `app.py` — код веб-приложения.
- `model.joblib` — обученный пайплайн (StandardScaler + LogisticRegression).
- `config.json` — файл с выбранным порогом отсечения.
- `test.csv` — тестовая выборка для расчетов метрик.
- `requirements.txt` — зависимости проекта.
